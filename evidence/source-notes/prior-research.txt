### 1. ParaView の基本仕様・制限・ライセンス

* **結果ファイルと表示情報の違い**
* **ファイル直接保存:** 節点座標、要素接続情報、各点の物理数値、時間ステップ。
* **ParaView側自動計算:** 要素数・節点数、物理量の最大/最小値、外形範囲（Bounds）、メモリ使用量。


* **対応不可・不得意な領域**
* メッシュ生成・境界条件設定・ソルバー計算実行（プリ・ソルバー機能）。
* 幾何形状の直接CAD編集・モデリング、高度なベクトル/PDFグラフ出力など。


* **結果ファイルから欠落・制限される情報**
* 解析の設定パラメータ（境界条件の種類、物性値、ソルバーの残差・収束履歴）。
* 高次要素の厳密な曲面幾何（描画時に1次要素へテッセレーション表示）。
* 単位系（Units）の自動識別（数値のみとして処理されるため手動管理が必要）。


* **商用利用とライセンス**
* **BSD 3-Clause ライセンス** のため無償で商用利用・自社ソフト組み込み・販売が可能。
* 著作権表示の保持と無保証（AS IS）への同意が条件。

### 2. データパイプラインと外部連携（Blender / Omniverse）

* **共通パイプライン（OpenUSD / OpenVDB）**
* 表面メッシュ・物理量カラーは `.usd`（`primvars:displayColor`）、体積・流体場は `.vdb`（OpenVDB）へ変換して結合。


* **Blender 連携と GPL 汚染回避**
* Blender コードの直接組み込みは GPL ライセンス感染を引き起こすため不可。
* **外部プロセスとして分離し、USD / VDB ファイル＋自動 Python スクリプトで連携** させることで、自社コードの権利を守りつつ、色や質感を100%保持したまま渡す設計がベスト。


* **NVIDIA Omniverse 連携**
* EULA 上、バイナリの同梱・再配布は不可だが、USD や Live Sync を介した外部コネクタ連携は可能。


* **自社ソフトに取り入れるべき高度な連携機能**
* **Zero-Copy（メモリ直接参照）:** 一時ファイル作成を挟まず RAM 上でデータ変換。
* **トポロジー固定の配列更新:** 時系列アニメーション時、メッシュ構造を保持したまま物理量配列のみを上書き更新。
* **ローカル擬似 Live Sync / 双方向コントロール:** WebSocket やソケット通信でパラメータ変更をリアルタイム反映。

### 3. CAEフォーマットの網羅と統一データモデル

* **ParaView (VTK) バックエンドによる統一**
* ParaView の Readers システムを自社ソフトに組み込むことで、100種類以上の解析フォーマットを読込可能。
* メモリ上で共通の **VTKデータ構造（`vtkUnstructuredGrid`, `vtkPolyData`, `vtkImageData`）** へ全自動で一元化され、一括して OpenUSD / OpenVDB に変換可能。


* **対応フォーマットの優先度**
* **Phase 1（最優先・全体の8割をカバー）:** OpenFOAM (`.foam`), CGNS (`.cgns`), EnSight (`.case`), VTK XML (`.vtu`/`.pvd`), STL (`.stl`)
* **Phase 2（主要CAE）:** Ansys Fluent (`.cas`), Abaqus (`.inp`), LS-DYNA (`.d3plot`), STEP/IGES
* **Phase 3（専門領域）:** NetCDF, HDF5, 各種ニッチソルバー

### 4. 自社プロダクト（CAE可視化＆3Dレポート自動化SaaS）の全容

#### ■ プロダクト概要・コアバリュー

* **製品定義:** FEA/CFDファイルから、プレゼン品質の3Dレポート（インタラクティブHTML等）を自動生成するデスクトップ＆Web対応型SaaS。
* **コアバリュー:** VTKによる「100%数値精度」と、USD/Blender/Omniverseによる「プレゼン・フォトリアル品質」を1クリックで架け橋する直感的ソリューション。

#### ■ アーキテクチャと展開形態

* **デスクトップアプリ（Electron）:** オフライン完全完結（セキュリティ最重要視のtoB向け）。
* **Web SaaS（React + WebGPU）:** クラウドでの手軽な共有・ブラウザ閲覧。

#### ■ データ構造（ワークスペース / ケース / 変数）

* **階層構造:** `Workspace` ➔ `Case` (親・子・孫の多重階層構造)。
* **変数継承ルール:** 親ケースの変数は子へ自動連動（継承）。子側での個別オーバーライドや「継承オフ」も設定可能。

#### ■ 主要機能群

* **可視化（View）:**
* レンダリング切り替え（VTK / Three.js / Omniverse / 3D Gaussian Splatting）。
* CAD風・2D三面図風・各種工学マテリアル・独自アートスタイルの適用。
* ボタン1つで見た目を維持したまま Blender へ全データ転送。


* **グラフ作成（Graph）:**
* マニュアル作成（カスタム数式・参考データ重ね合わせ）。
* 機械的レコメンド ＆ LLM推論によるおすすめグラフ自動提案。


* **自動解析・Diff比較:**
* ケース間の物理量差分（例: $\Delta P = P_{case2} - P_{case1}$）の自動可視化。
* 将来的に外部CAEソルバーの自動ループ実行連携に対応。


* **レポート（Report）:**
* インタラクティブ3Dビュー付きHTMLレポート出力（主軸）。
* PowerPoint / Word / Excel / 画像 / 動画 出力。
* 機械的考察および LLM 連動の自動考察執筆。


* **LLM / 自然言語操作 & RAG:**
* 自然言語による全操作（Chat UI）。
* 外部LLMからの完全自動制御（Headless Agent Mode）。
* 参考資料（仕様書PDF等）のRAG参照（数値ファクトを絶対優先する優先順位制御）。
